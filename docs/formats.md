# On-disk formats and the compatibility promise

Sakura accumulates state the user would hate to lose. These rules hold from 0.9.7:

1. **The shapes below are v1, with or without a `v` field.** Existing stores stay as they are; stores born after 0.9.7 carry `"v": 1`. Readers never crash on either.
2. **Readers ignore fields they don't know.** New code may add fields; old code keeps working past them.
3. **A field, once shipped, keeps its name and meaning.** Renames happen by adding the new field and reading both for two releases.
4. **A breaking change bumps `v`**, and the reader that bumps it migrates the old shape in place, once, keeping a `.bak` next to it.
5. **Plain-text stores (memory, `.sakura.md`, decisions.jsonl lines) never get structure added** that a human couldn't have typed.

| Store            | Path                                                        | Shape                                                                                                                                                                                 |
| ---------------- | ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| pa schedule | `~/.sakura/pa/schedule.json` | a list of `{id, kind: reminder\|job\|watch\|command\|mail, at, rule, host?, pin?, …}`; `rule` is `{n, unit, clock, weekday?, day?, month?, anchor?}` |
| pa claims | `~/.sakura/pa/claims/ID@YYYYMMDDTHHMMSS.HOST.json` | `{id, occ, host, claimed, fired, next?, item, tries?}`, one per occurrence per machine, kept a week; `ID@gone.HOST.json` is `{id, host, claimed, cancelled: true}` |
| pa machines | `~/.sakura/pa/hosts/HOST.json`, `autoreply-by/HOST.json` | `{host, seen, active?}`; `{at}`. Each machine writes only its own, so a file sync never has two versions to merge |
| pa wake stamp | `~/.local/state/sakura/pa/HASH-HOST.json` | `{tick, woke}`; this machine only, never synced, written only when other machines share the schedule |
| pa offers        | `~/.sakura/pa/offers.json`                                  | list of `{id, text, command, cwd, expires, done?}`                                                                                                                                    |
| pa settings      | `~/.sakura/pa/settings.json`                                | flat keys; `mail_rules: {urgent: [], mute: []}`                                                                                                                                       |
| night shift      | `~/.sakura/tonight/queue.json`                              | `{at, seq, jobs: [{id, dir, settings, brief, status, …}]}`                                                                                                                            |
| guardian         | `~/.sakura/guardian/config.json`, `seen.json`, `disk.jsonl` | `{backups: {name: {path, every, restored?}}, certs?}`; seen: text→epoch; disk: one `{t, d}` per line                                                                                  |
| downloads        | `~/.sakura/dl/queue.json`                                   | `{v, items: [{id, url, file, total, state, sha256?, checksum?}]}`                                                                                                                     |
| logs mutes       | `~/.sakura/logs-mutes.json`                                 | `{v, items: [{pattern, added, hits}]}`                                                                                                                                                |
| drive syncs      | `~/.sakura/drive/syncs.json`                                | list of `{id, src, dest, until, pid, started}`                                                                                                                                        |
| torrents         | transmission's own config dir                               | transmission's format, not ours                                                                                                                                                       |
| backups          | `~/.sakura/backup/NAME.json` + `NAME.pass` (0600)           | `{v, dest, sources, excludes}`; the password file is sacred                                                                                                                           |
| procwatch        | `~/.sakura/procs/NAME.json`                                 | `{pid, command, cwd, started}`                                                                                                                                                        |
| vid archives     | `~/.sakura/vid/NAME.json`, `NAME.archive`, `NAME.log`       | `{v, name, url, dir, runs, started, finished, rc, before, after, new, pid}`; the `.archive` is yt-dlp's own `extractor id` per line                                                   |
| faces index      | `~/.sakura/faces/index.json`                                | `{v, files: {path: "size:mtime"}, faces: [{path, box, score, emb[512], cluster}], names: {cluster: name}}` — the only copy of the signatures                                          |
| restore binaries | `~/.local/share/sakura/restore/`                            | a cache of two GitHub release zips, re-fetchable                                                                                                                                      |
| vault            | `~/.password-store`                                         | pass's own layout (gpg files; `login:`/`url:`/`notes:` lines after the password; otpauth lines for pass-otp), not ours                                                                |
| model choices    | `~/.sakura/models.json`                                     | `{v, roles: {ROLE: TAG}, drivers: {NAME: {repo, file, revision, size, sha256}}}` — `sakura-model pick` writes it; size and sha256 of your own driver are pinned on its first download |
| catalog          | `~/.sakura/catalog.json`                                    | a cache: the repo's models.json plus an entry per picked chat model; rebuilt on every launch                                                                                          |
| money            | `~/.sakura/money/journal.ledger`, `rules/BANK.rules`        | hledger's own journal and CSV-rules formats, not ours; edit freely                                                                                                                    |
| signing key      | `~/.sakura/sign/key.pem` (0600), `cert.pem`                 | PEM from openssl; the key never leaves the machine; back both up                                                                                                                      |
| vid watches      | `~/.sakura/vid/NAME.seen.json`                              | `{v, url, ids: [], checked}` — the video ids already shown as new                                                                                                                     |
| decisions        | `~/.sakura/decisions.jsonl`                                 | one `{when, text, dir, repo, branch, commit}` per line, append-only                                                                                                                   |
| memory           | `~/.sakura/memory/*.md`                                     | plain text, one fact per line, synced through dotfiles                                                                                                                                |
| undo store       | `~/.sakura/undo/`                                           | managed by the root-owned guard; its format changes only with a guard release                                                                                                         |
| recall index     | `~/.cache/sakura/recall.db`                                 | a cache: safe to delete, rebuilt on next use                                                                                                                                          |
| kept tools       | `~/.sakura/tools/{bin,meta}`                                | the script plus `{about, check}`; the check re-proves it on any machine                                                                                                               |

Caches (`~/.cache/sakura/*`) carry no promise: deleting them costs a rebuild, nothing else.

## File formats `conv` turns into each other

`conv` keeps no state of its own. What it reads and writes are other people's formats, and which tool does a pair is fixed
below so the answer is the same on every machine. An output never replaces a file that is already there (`name (2).ext`), and
`conv --tools` says which of these tools are installed and the line that installs each one that isn't.

| From                            | To                                                                                            | Tool                                                                                                                     | Proven by                                                                                   |
| ------------------------------- | --------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------- |
| md, docx, html, odt, rst, txt   | epub, fb2                                                                                     | pandoc; the title is the document's own, else `--title`, else the file name                                              | `evals/formats.py` books                                                                    |
| epub, fb2                       | md, docx, html, txt, odt, epub, fb2                                                           | pandoc; title and author become front matter in md                                                                       | `evals/formats.py` books                                                                    |
| epub, mobi, azw3, azw, fb2, pdf | mobi, azw3, epub, fb2, pdf, txt, docx, rtf                                                    | calibre `ebook-convert`; title and author kept                                                                           | `evals/formats.py` kindle                                                                   |
| md, rst, org, tex               | mobi, azw3                                                                                    | pandoc → epub, then calibre                                                                                              | `evals/formats.py` kindle                                                                   |
| mobi, azw3                      | md, html, odt                                                                                 | calibre → epub, then pandoc                                                                                              | `evals/formats.py` kindle                                                                   |
| epub, fb2                       | pdf                                                                                           | calibre; without it pandoc → html → LibreOffice                                                                          | `evals/formats.py` kindle                                                                   |
| docx, odt, rtf, pptx, xlsx, ods | pdf, and each other within a kind                                                             | LibreOffice, into a temporary folder first                                                                               | `evals/formats.py` office                                                                   |
| xlsx, xls, ods                  | csv (UTF-8; one file per sheet, `book Sheet.csv`, when there are several; formulas as values) | LibreOffice                                                                                                              | `evals/formats.py` office                                                                   |
| csv                             | xlsx, ods, pdf                                                                                | LibreOffice                                                                                                              | `evals/formats.py` office                                                                   |
| scanned pdf, image              | searchable pdf (`conv ocr`)                                                                   | ocrmypdf (`--skip-text`); tesseract alone for an image                                                                   | `evals/formats.py` ocr                                                                      |
| audio, video                    | the same container, hiss removed (`conv denoise`)                                             | ffmpeg `afftdn` (`nr` = `--strength`, `nf` = `--floor` or measured), `arnndn` with `--model`; the video stream is copied | `evals/formats.py` denoise                                                                  |
| audio, video                    | a folder of stems (`conv stems`)                                                              | Demucs; its own model, fetched by Demucs on first use                                                                    | `evals/formats.py` stems (the plumbing; a real separation is skipped where the model isn't) |

Not done by anything here: removing DRM from a bought book (calibre refuses, and so does `conv`), and writing `.azw` (Kindles
read `azw3`). mobi and azw3 have no path without calibre: `conv` says so, names the install line and writes nothing.
